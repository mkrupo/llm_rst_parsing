Analyze the target TSV document and return one complete compact discourse tree.
Refer to text fragments only by their index.

OUTPUT CONTRACT:
- Return exactly one tree and no other text or Markdown.
- Each leaf must have the form `(text INDEX)`.
- Use every input index exactly once, in the same left-to-right order as the TSV.
- Do not alter the supplied segmentation.
- A mononuclear node is `(NS-RELATION LEFT RIGHT)` or `(SN-RELATION LEFT RIGHT)`;
  the two letters give the nuclearity of the left and right child respectively.
- A multinuclear node is `(NN-RELATION CHILD CHILD ...)` and has at least two children.
- Use `NN` only with a multinuclear relation and `NS` or `SN` only with an RST relation.
- Relation identifiers are case-sensitive. Use only these exact identifiers:
  attribution, background, antithesis, concession, evidence, reason, reason-n,
  justify, evaluation-s, evaluation-n, motivation, enablement, circumstance,
  condition, otherwise, unless, elaboration, e-elaboration, interpretation,
  means, cause, result, purpose, solutionhood, preparation, restatement, summary,
  same-unit, contrast, sequence, list, conjunction, joint.

```text
PRECHECK:
Apply the omission test to determine whether the candidate relation is mononuclear
or multinuclear.

If one span can be omitted while the other still performs the same local text function,
    mark the indispensable span as NUCLEUS
    and the omissible/supporting span as SATELLITE.

If both spans remain independently functional and equally central,
    treat the relation as MULTINUCLEAR.

Use relation definitions to validate nuclearity.
```

```text
If discontinuous fragments are parts of one interrupted EDU, then
    assign same-unit to the fragments that form that EDU
```

```text
If several adjacent spans play the same role with respect to a larger segment, then
    if they are explicitly linked by coordinating connectives such as "and", "or",
    "also", or "in addition"
        assign conjunction
    else
        assign list
```

```text
If the omission test indicates that neither span is more nuclear, then
    if the spans describe states of affairs in temporal order
        assign sequence
    else if exactly two spans are comparable but differ in writer-relevant respects
        assign contrast
    else if the spans enumerate comparable information
        if there is a coordinating connective
            assign conjunction
        else
            assign list
    else
        assign joint
```

```text
Else, if the omission test identifies NUCLEUS and SATELLITE,
test primarily pragmatic relations before semantic ones.
```

```text
If one span is the source of reported speech, thought, perception, or feeling
and the other span is its attributed content, then
    assign attribution
```

```text
If S makes it easier for R to understand N, especially by providing necessary
prior/topic information, then
    assign background
```

```text
Else if the relation is adversative, contrastive, or expectation-violating, then
    if neither span is more nuclear by the omission test
        assign contrast
    else if S is acknowledged as true/valid but N still holds against expectation
        assign concession
    else if S is the rejected or less important thesis and W identifies with N
        assign antithesis
```

```text
Else if S supports a subjective claim, thesis, or evaluation in N, then
    if S is presented as objective fact, observation, or acceptable evidence
        assign evidence
    else if S is also a subjective claim/thesis by W
        assign reason
    else if S supports W’s right to present N or gives a basic justificatory stance
        assign justify
```

```text
Else if the support relation runs in the other direction,
and the omission test shows that the supporting/reason-giving span is more nuclear,
    assign reason-n
```

```text
Else if one span evaluates the other from W’s perspective, then
    if the evaluation is omissible and the evaluated material remains central
        assign evaluation-s
    else if the evaluation is the central point and the evaluated material is supporting
        assign evaluation-n
```

```text
Else if N is an action to be performed by the reader, then
    if S increases R’s desire to perform N
        assign motivation
    else if S increases R’s ability to perform N
        assign enablement
```

```text
Else if the relation involves unrealized, hypothetical, future, or potential situations, then
    if N is an activity/action and S is the unrealized goal achieved through N
        assign purpose
    else if realizing N prevents or impedes realizing S
        assign otherwise
    else if N is realized only if S is not realized
        assign unless
    else if realization of N depends on realization of S
        assign condition
```

```text
Else if the relation is factive causality, then
    if S causes N and the omission test makes N central
        assign cause
    else if N causes S and the omission test makes N central
        assign result
```

```text
Else if N is an activity/action and S gives the instrument, method, or way
that makes N possible or easier, then
    assign means
```

```text
Else if S presents a problem and N presents a solution, then
    assign solutionhood
```

```text
Else if S provides an actual temporal, locative, or situational framework
for interpreting N, then
    assign circumstance
```

```text
Else if S shifts N into a different conceptual frame without primarily evaluating it, then
    assign interpretation
```

```text
Else if S provides detail or more information about N, then
    if S elaborates a single entity mentioned in N
        assign e-elaboration
    else
        assign elaboration
```

```text
Else if the relation is mainly textual or organizational, then
    if S precedes N and merely orients R toward N
        assign preparation
    else if S repeats N with different wording and roughly equal size
        assign restatement
    else if S follows a multi-EDU N and gives a shorter restatement
        assign summary
```

```text
Else
    if both spans are equally important
        assign joint
    else
        choose the most informative applicable relation rather than a vague one.
```
